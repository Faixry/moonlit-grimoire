# Moonlit Grimoire v2

Interactive static learning website with:
- blue/green/teal visual theme
- lesson completion tracking
- browser-saved notes
- quiz accuracy statistics
- lesson/note statistics
- research/source cards
- light/dark toggle
- responsive mobile layout

## Publish on GitHub Pages
Upload `index.html`, `style.css`, and `script.js` to the root of a public GitHub repository. Go to Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## Research approach
The site intentionally distinguishes historical/folkloric claims from scientific evidence. For example, the crystal lesson links to a 2025 randomized controlled study of 138 adults that found no anxiety effect beyond placebo. Historical lessons link to the Institute of Historical Research, British Museum, and World History Encyclopedia.
